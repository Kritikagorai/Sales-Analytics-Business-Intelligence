# 📊 Sales Analytics & Business Intelligence

> An end-to-end Sales Analytics and Business Intelligence project designed to transform raw sales data into meaningful business insights through data analysis, visualization, KPIs, and an interactive dashboard.

## 🔗 Project Repository

**GitHub:**
https://github.com/Kritikagorai/Sales-Analytics-Business-Intelligence

## 📌 Project Overview

The **Sales Analytics & Business Intelligence** project analyzes sales data to understand overall business performance and identify important patterns, trends, and opportunities.

The project converts raw sales data into useful insights related to:

* 💰 Total Sales & Revenue
* 📈 Monthly and Weekly Sales Trends
* 🏆 Best-Selling Products
* 🏷️ Product Category Performance
* 🌍 Regional Performance
* 👥 Customer Behaviour
* 💵 Profit & Loss Analysis
* 📅 Seasonal Sales Patterns
* ⚠️ Low-Performing Products
* 📊 Business KPIs and Statistics

The main objective is to help businesses make **data-driven decisions** by presenting important information in a simple and interactive format.

## 📈 Business Insights

The project is designed to answer important business questions such as:

### Which month has the highest sales?

The monthly sales analysis identifies the highest-performing month and helps understand the factors that may have contributed to increased sales.

### Which month has the lowest sales?

The analysis identifies low-performing periods that may require additional marketing, pricing, or promotional strategies.

### Which products sell the most?

Product-level analysis helps businesses identify their best-performing products and focus on products with higher demand.

### Which region performs best?

Regional analysis helps compare sales performance across different geographical areas.

### Which categories contribute the most?

Category-level analysis shows which product groups generate the largest share of sales.

### Where are the opportunities for improvement?

Low-performing products, categories, regions, and periods can be identified for further investigation and improvement.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Kritikagorai/Sales-Analytics-Business-Intelligence.git
```

### 2. Open the project

```bash
cd Sales-Analytics-Business-Intelligence
```

### 3. Install dependencies

```bash
pnpm install
```

Or:

```bash
npm install
```

### 4. Start the development server

```bash
pnpm dev
```

Or:

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:3000
```
